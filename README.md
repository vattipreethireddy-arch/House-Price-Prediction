🏠 House Price Prediction
A simple Machine Learning project that predicts house prices using Square Footage, Bedrooms, and Bathrooms.
🛠️ Technologies
Python
Pandas
NumPy
Scikit-learn
Linear Regression
📌 Features
Train a Linear Regression model
Predict house prices
Evaluate the model using MAE, MSE, and R² Score
▶️ How to Run
1. Clone the repository
git clone https://github.com/your-username/HousePriceML.git
cd HousePriceML
2. Install required libraries
pip install pandas numpy scikit-learn matplotlib seaborn
3. Run the program
python houseprice.py
